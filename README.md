# BrowserRAMSaver

**BrowserRAMSaver** is a browser extension designed to help reduce RAM usage while browsing and make the browsing experience smoother.

**إضافة للمتصفح تساعد على تقليل استهلاك الذاكرة (RAM) أثناء التصفح، بهدف جعل المتصفح أخف وأكثر سلاسة.**

## Features

* Helps reduce memory usage while browsing.
* Simple and lightweight.
* Easy to install.
* Designed for browsers that support Chromium extensions.

## Installation

1. Download or clone this repository.
2. Extract the files if you downloaded them as a ZIP.
3. Open your browser's Extensions page.
4. Enable **Developer Mode**.
5. Select **Load unpacked**.
6. Choose the folder containing `manifest.json`.
7. The extension will be installed and ready to use.

## Supported Browsers

The extension is intended for browsers that support Chromium extensions, such as:

* Google Chrome
* Microsoft Edge
* Brave
* Opera
* Other Chromium-based browsers
